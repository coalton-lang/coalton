`pprint-coalton-codegen` pretty-prints the Common Lisp code generated by [`coalton-codegen`](/manual/operators/coalton-codegen/) to `*standard-output*`.

## Syntax

```lisp
(pprint-coalton-codegen
  ⟨toplevel-form⟩*)
```

## Semantics

- `pprint-coalton-codegen` accepts the same top-level forms as [`coalton-toplevel`](/manual/operators/coalton-toplevel/).
- It compiles the forms via [`coalton-codegen`](/manual/operators/coalton-codegen/) (with host type declarations omitted) and pretty-prints the resulting Common Lisp `(progn ...)` form to `*standard-output*`.
- Before printing, it creates a temporary package that uses `#:cl` and imports all symbols accessible in the current `*package*`, so user and Coalton symbols print cleanly without redundant package prefixes, and deletes the temporary package via `cl:unwind-protect`.
- Returns zero values `(cl:values)`.

## Examples

```lisp
;; Replace `coalton-toplevel` with `pprint-coalton-codegen` to inspect generated Lisp
(pprint-coalton-codegen
  (declare sum-upto (UFix -> UFix))
  (define (sum-upto n)
    (for ((i 0 (+ i 1))
          (acc 0 (+ acc i)))
      :returns acc
      :while (< i n))))
```

## Other Notes

- Use [`pprint-coalton-codegen-types`](/manual/operators/pprint-coalton-codegen-types/) when you also want to inspect the emitted Common Lisp `(declare (type ...))` and `(the (values ...) ...)` annotations.
- See [Debugging](/manual/topics/debugging/) and [Performance and Optimization](/manual/topics/performance-and-optimization/).
